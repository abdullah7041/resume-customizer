================================================================================
EXPLANATION: WHY "0/15" APPEARS
================================================================================

USER FLOW:
  1. User logs in -> auth.users row exists
  2. useUserCredits hook executes
  3. Hook: SELECT FROM user_credits WHERE user_id = ?
  4. Error: "relation 'user_credits' does not exist" (PGRST116)
  5. Hook catches error, tries fallback INSERT
  6. INSERT also fails (table doesn't exist)
  7. Hook returns credits = null
  8. CreditBalance component: if (!credits) return null;
  9. Parent component defaults or shows "0/15"
  10. User sees broken state

CODE EVIDENCE:
  - src/hooks/useUserCredits.tsx:36-48
