# Developer Profile

## Product

Watheq is a proprietary resume optimizer for Saudi Arabia's job market. It should preserve user truth, support Arabic/English workflows, and produce ATS-friendly resume guidance aligned with real job evidence.

## Collaboration Style

- Be concise, direct, and implementation-oriented once the task is clear.
- For bugs, state the root-cause diagnosis before proposing or writing fixes.
- For feature work, explain the architecture impact before editing app code.
- Keep agent instructions durable and small; avoid copying large persona text or transient task notes into repo guidance.

## Product Priorities

- Do not invent resume facts or inflate scores.
- Preserve schema integrity and user-owned resume data.
- Treat AI output as suggestions unless the user explicitly applies it.
- Respect proprietary licensing language already present in the repo.
