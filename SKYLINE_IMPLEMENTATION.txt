## Implementation Details

### Core Functions (Already Implemented in `src/lib/assets.ts`)

#### 1. `publicAssetUrl(bucket, objectPath)`
- **Location:** Lines 258-277
- **Features:**
  - Validates and normalizes bucket name and object path
  - Builds deterministic public URL: `{origin}/storage/v1/object/public/{bucket}/{objectPath}`
  - Adds `apikey` query param for Supabase hosts
  - Returns empty string on invalid env (no crash)

#### 2. `getSkylineUrl()`
- **Location:** Lines 285-302
- **Features:**
  - Calls `publicAssetUrl("ui-assets", "KAFDH.webp")`
  - Adds version query param via `withVersion()`
  - Falls back to gradient SVG on failure
  - Memoized for performance (called only once)
  - Never crashes - always returns a valid URL

#### 3. `ensureHostOnlyUrl(value, sourceKey)`
- **Location:** Lines 140-174
- **Features:**
  - Validates URL is host-only (https://host.tld)
  - Coerces pathful URLs to origin
  - Warns in DEV mode when coercion occurs
  - Only warns once per unique message

### Validation & Fallback Flow

```
1. Read VITE_ASSETS_BASE_URL || VITE_SUPABASE_URL
   ↓
2. Validate is host-only URL
   ↓ (if path detected)
3. Coerce to origin + warn in DEV
   ↓
4. Build public URL: {origin}/storage/v1/object/public/ui-assets/KAFDH.webp
   ↓
5. Add version query param
   ↓ (on any error)
6. Fallback to gradient SVG
```
