# GEIDEA Integration Implementation Plan

**Goal:** Deliver a gated sandbox checkout and verified payment ledger from the November 10 GEIDEA email.
**Architecture:** Hosted KSA checkout, server-owned SAR 1 test amount, service-role persistence, signed callbacks verified against authenticated order reads. No paid entitlement is inferred from the planned monthly price.
**Tech stack:** Existing React, Netlify Functions, Zod, Supabase, Node crypto, Vitest. No dependencies added.
**Spec:** `docs/superpowers/specs/2026-11-10-geidea-design.md`

## Constraints and review focus

Keep existing user changes intact; never commit credentials; never apply database migrations. Reject unknown body fields, forged callbacks, amount/reference/session/merchant mismatches, and real orders. Keep success monotonic under duplicate/delayed callbacks. Preserve public waitlist and credit behavior.

## Execution record

- Gateway, handler and UI tests first failed because their modules did not exist, then passed after implementation. A real sandbox session exposed a stricter-than-provider UUID validator; its reproducer failed before the GUID-shape fix and passed after it.
- Real Visa, Mastercard and mada hosted test transactions succeeded and passed the authenticated order verifier. This does not establish deployed callbacks or SQL execution; see `docs/geidea-integration.md`.
- The user requested market research before choosing paid benefits. Regional/global research and a concrete SAR 9 / 20-credit proposal are saved in `docs/research/2026-11-10-pricing-decision.md`; no commercial offer was activated.
- Independent review found no blocking defect. Its documentation finding was corrected: GEIDEA's documented fetched-order schema has no session ID, so verified binding is merchant + random reference + order + amount + currency + test flag, with a saved session prerequisite.
- SQL replay/concurrency behavior is inspected only, not executed. Pending ledger state can persist if callback delivery is exhausted; deployment qualification and reconciliation remain documented limits. No migrations, production deploy, outreach, or entitlement changes were performed.
